# 遠端狀態擷取（Fetch）

安全擷取遠端儲存庫的最新提交與標籤，並自動嘗試快轉更新所有非當前所在之本地分支。

## 什麼時候觸發此技能？

1. 當使用者輸入 `/antigravity-github-flow:agy-github-flow:fetch`。
2. 當使用者提及「幫我 fetch」、「擷取遠端」、「更新遠端資訊」時。
3. 作為 `pull` 技能執行時的**強制前置動作**。

## 核心設計原則

1. **零污染當前工作區**：
   - 依照 Git 原生設計與安全規範，目前正在簽出的分支（Current Branch）必須由 `pull` 技能負責將更新整併至工作目錄，fetch 階段**嚴格跳過目前分支的本地指標變更**，僅擷取遠端物件並彙整目前分支落後/超前狀態。
2. **非當前分支多軌本地快轉**：
   - 掃描所有非當前的本地分支，若該分支有對應的遠端追蹤分支且本地落後遠端（可進行 Fast-Forward 快轉）：
   - 使用本地快轉機制在背景直接更新本地分支指標，省去手動切換分支再 pull 的繁瑣步驟。
3. **「不行的話就算了」原則**：
   - 若本地分支已有未推播的提交、與遠端發生分叉（Diverged）、在其他 Git Worktree 中被簽出，或是無對應遠端分支：
   - 系統**安全略過**並保留原狀，不報錯亦不強行覆寫，貫徹「不行的話就算了」安全哲學。

## 執行的實作步驟

重要提示：關於腳本執行路徑，由於本技能作為 Plugin 載入，請從您的系統提示詞 `<skills>` 列表中，找出 `antigravity-github-flow:agy-github-flow:fetch`（或 `fetch`）技能被載入的絕對路徑（位於括號中）。請解析該絕對目錄位置，並替換為 `scripts/` 資料夾的絕對路徑後執行腳本（例如：`node /絕對路徑/scripts/fetch.js`），絕不可使用相對路徑。

1. **第一步：執行 Fetch 診斷與更新腳本**
   透過 `run_command` 執行輔助腳本：
   ```bash
   node <腳本絕對目錄>/scripts/fetch.js
   ```
   腳本會自動完成：
   - 執行 `git fetch --all --prune --tags` 下載全域最新物件。
   - 掃描所有本地分支並安全快轉非當前分支。
   - 檢查當前分支相對於遠端 upstream 的落後（behind）與超前（ahead）提交數量。

2. **第二步：結果彙整回報**
   向使用者條列說明：
   - 遠端擷取與已同步標籤狀態。
   - 非當前分支的快轉更新結果（若有無法快轉者，說明「因本地有分叉或無遠端分支已安全略過（不行的話就算了）」）。
   - 當前分支狀態：
     - 若當前分支有落後提交（behind > 0）：主動建議使用者執行 `/antigravity-github-flow:agy-github-flow:pull` 進行拉取。
     - 若當前分支已是最新狀態：告知使用者工作區已是最新。
